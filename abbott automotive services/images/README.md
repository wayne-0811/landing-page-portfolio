The homepage is built with **no stock photography** (a hard rule in `../CONTEXT.md`).
Each photo slot in `index.html` is a labelled placeholder with the real `<img>` tag
sitting commented-out right above it. To go live, drop the file in with the name below
and uncomment the `<img>`.

is already used on the page; their *images* are not.
